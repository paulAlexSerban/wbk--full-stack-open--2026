# Full Stack Open 2026 - Submissions

This repository contains my exercises for the [Full Stack Open](https://fullstackopen.com/en) course from the University of Helsinki.

## Part 0: Fundamentals of Web Apps
- **Exercise 0.4:** New note diagram (Traditional web app logic) (POST /notes)
- **Exercise 0.5:** Loading single page app sequence diagram (GET /spa)
- **Exercise 0.6:** New note in single page app sequence diagram (POST /new_note_spa)

## Project Structure
The exercises are organized by parts:
* `part0/`: Diagrams and basic web concepts.

## How to Run
*For Part 0, the exercises consist of Mermaid.js diagrams or image files.*
1. Navigate to the `part0/` directory.
2. Open the `.md` or files to view the sequence diagrams.

## Technologies Used
* HTML/CSS
* JavaScript
* Mermaid.js (for sequence diagrams)
